# P08 — Claude/Codex Handoff Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When `shelf doc add` is invoked without the classification flags it needs, launch the configured AI agent (`claude`/`codex`) with the `shelf-add` skill primed — unless the CLI is already inside an AI session (never nest) or handoff is suppressed (`--no-handoff`/`--no-input`), in which case missing flags are a clean error.

**Architecture:** A new `core/handoff.py` (session detection via env vars, agent-precedence resolution, primed-prompt builder, and a `_launch_handoff` exec seam mirroring the `_gh` seam) plus a pre-mutation branch at the top of `cli/doc_add.py`. The `--kind/--title/--description` options drop `required=True` so Click no longer forecloses the handoff; a post-parse check decides handoff vs. error vs. proceed. The `shelf-add` skill itself is **out of scope** (deferred to the separate `shelf-skill` repo, PRD §12) — P08 ships only the CLI-side launcher.

**Tech Stack:** Python 3.12, click, pytest, `os.execvp` for the terminal handoff, `subprocess`-style seam mocking (monkeypatch).

## Global Constraints

- **Spec of record:** SHELF-PRD.md §11.2 (`shelf doc add` handoff), §5 / standards §7-§8 (`--no-input` never prompts and never hands off; missing classification flags then exit `2`), §14 item 4 (AI-session detection is build-time-verified).
- **Handoff trigger:** the *required classification flags* are `--kind`, `--title`, `--description`, and exactly one anchor (`--repo` **or** `--topic`). The handoff fires when **any** of these is missing. Providing **both** `--repo` and `--topic` is a contradictory invocation → `UsageError` (exit 2), never a handoff.
- **Decision order when required flags are missing** (suppression-first, so `--no-input` always exits 2 even inside a session, per PRD §5 which is explicit that `--no-input` + missing classification → exit 2): (1) if `--no-handoff` **or** `--no-input` → `UsageError` (exit 2) naming the missing flags; (2) else if inside an AI session → `ClickException` (exit 1) telling the assistant to invoke the `shelf-add` skill directly (never nest a session); (3) else → launch the handoff agent. `--no-input` implies `--no-handoff`. Rationale: in-session detection only matters when we would actually launch; if handoff is suppressed there is nothing to nest, so suppression is checked first.
- **Agent precedence:** `--handoff-agent <claude|codex>` flag → `handoff-agent` config key (already exists, default `claude`) → `claude`. Only `claude` and `codex` are valid.
- **Primed prompt (exact shape, PRD §11.2):** `Use the shelf-add skill to add <`\``paths`\``> to shelf. Walk me through classification.` — each input path backtick-quoted, comma-separated.
- **Session markers (build-verified):** Claude Code → `CLAUDECODE` present/non-empty; Codex → `CODEX_THREAD_ID` present/non-empty (canonical by shipped Codex CLI 0.144.6 behavior; the closest analogue to `CLAUDECODE`).
- **Launcher failure mode:** the agent binary missing from `PATH` surfaces a clean `click.ClickException`, mirroring how `_gh`/`git_init` wrap `CalledProcessError` (P07) — never a raw traceback.
- **No mutation before handoff:** the handoff branch runs before the library lock and before any catalog load — it is a pure pre-check + `exec`.
- **Out of scope:** the `shelf-add` skill (lives in `shelf-skill`), any change to the config filename, and the `browser` config key.

```python
"""shelf doc add handoff (PRD §11.2) — launch the configured AI agent when
classification flags are missing, unless already inside an AI session."""

import os
from pathlib import Path
from typing import NoReturn

import click

_VALID_AGENTS = ("claude", "codex")


def in_ai_session() -> str | None:
    """Return the AI session label if running inside one, else None.

    Claude Code sets CLAUDECODE; Codex sets CODEX_THREAD_ID (Codex CLI 0.144.6).
    """
    if os.environ.get("CLAUDECODE"):
        return "Claude Code"
    if os.environ.get("CODEX_THREAD_ID"):
        return "Codex"
    return None


def resolve_agent(flag: str | None, cfg_agent: str) -> str:
    """Resolve the handoff agent: flag > config > (config default 'claude')."""
    agent = flag or cfg_agent
    if agent not in _VALID_AGENTS:
        raise click.ClickException(
            f"unknown handoff agent '{agent}' — use one of {', '.join(_VALID_AGENTS)}"
        )
    return agent


def build_handoff_prompt(paths: list[Path]) -> str:
    """Build the primed introductory prompt referencing the shelf-add skill."""
    listed = ", ".join(f"`{p}`" for p in paths)
    return f"Use the shelf-add skill to add {listed} to shelf. Walk me through classification."


def _launch_handoff(agent: str, prompt: str) -> NoReturn:
    """Replace this process with the agent, seeded with the primed prompt.

    Isolated seam (like core.git._gh) so tests mock os.execvp. On success the
    process image is replaced and nothing after this returns.
    """
    try:
        os.execvp(agent, [agent, prompt])
    except FileNotFoundError as exc:
        raise click.ClickException(
            f"handoff agent '{agent}' is not installed or not on PATH"
        ) from exc


def run_handoff(agent: str, paths: list[Path]) -> NoReturn:
    """Build the primed prompt and hand off to the agent (execs; never returns)."""
    _launch_handoff(agent, build_handoff_prompt(paths))
```
