# P07 Git and GitHub Integration Implementation Plan (v0.7.0)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to execute this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** `--commit`/`--commit-message` across every mutating command, and `shelf init --git` / `--github` / `--owner` — so a library is a git repo, mutations can auto-commit, and a private GitHub remote can be created at init.

**Architecture:** A `core/git.py` (stdlib subprocess over the `git` CLI + a `gh` seam) and a `cli/commit.py` (a `commit_options` decorator, a fail-fast git precheck, and a shared commit-after-mutation helper). Every mutating command gains `--commit`/`--commit-message` uniformly and commits inside its existing lock, after `commit_library`, before any source removal (§5 order). `--github` is the phase's **live-state** surface — opus pilots it against a real scratch repo with rollback before the gate.

**Tech Stack:** As P06 (stdlib subprocess; `git` and `gh` on PATH). No new deps.

**Agent assignments:** red sonnet · green codex (write full files; stage or stop; controller commits; sandbox can't reach the network so controller runs any network-touching check) · **Task 4 gate: fable + codex concur on the live pilot; opus pilots `init --github` once against a scratch repo with rollback** · haiku flips.

## Global Constraints

- Spec of record: SHELF-PRD.md §11 common conventions (`--commit` default off; auto message `shelf: <verb> <subject>`, e.g. `shelf: doc add <slug>`; `--commit-message` override; `--commit` requires a git repo and errors otherwise; `shelf init` is the exception — its commit is governed by `--git`, not `--commit`), §11.1 (`init --git/--github/--owner`), §5 (commit after index regen, before source removal), §11.6 check 5 (dirty git — already implemented).
- Auto-message convention per command: `shelf: doc add <slug>` · `shelf: doc format add <slug> <fmt>` · `shelf: doc format delete <slug> <fmt>` · `shelf: doc update <slug>` · `shelf: doc move <slug>` · `shelf: doc delete <slug>` · `shelf: doc adopt <slug>` · `shelf: orphan delete <path>` · `shelf: topic add <name>` · `shelf: kind add <name>` · `shelf: migrate` · `shelf: regen`.
- `--commit` on a non-git library → **fail fast before any mutation** with a clear ClickException (exit 1) naming `shelf init --git`. Never mutate-then-fail. The precheck (`.git` presence) is advisory; `git_commit_all` itself is the authority and raises a ClickException on any git failure (leaving the already-mutated library valid-but-uncommitted, which audit check 5 flags).
- The git commit runs **OUTSIDE the library lock**, after the command's final in-library filesystem change (Codex review — committing inside the lock would deadlock if the user has the `shelf audit` pre-commit hook, since git spawns the hook as a subprocess that re-acquires `library_lock`; it is also too early for delete/move/format-delete whose file cleanup runs after `commit_library`). Order: `with library_lock: mutate → commit_library → file cleanup (rmtree/unlink)`; then, after the lock releases, `git_commit_all`; then source removal (doc add / doc format add — sources live outside the library root, so `git add -A` never stages them).
- `.shelf.lock` is never committed: `shelf init --git` writes a library `.gitignore` containing `.shelf.lock` so `git add -A` never stages it.
- shelf uses the **ambient git identity** (the user's git config) — it never invents a committer. Tests provide identity via an isolated git env.
- `--github` runs `gh repo create <owner>/<name> --private` (default name `shelf-library`; `--owner` defaults to the authenticated `gh` user) then sets the remote; implies `--git`. A `_gh(args)` seam makes it mockable; the real path is opus-piloted only.
- Implementers never edit `tests/`; **disclosure rule** in force. Conventional Commits + trailer:
  `Claude-Session: https://claude.ai/code/session_015GDbGv8iA9Zd4iBfY1b2Zx`
- Worktree branch `p07-git-github`; `just all` run **unpiped** at the gate.

## Plan-level decisions (recorded for the gate)

1. **`--commit` is cross-cutting via a decorator + two helper calls, commit OUTSIDE the lock.** `commit_options` (like `output_options`) adds `--commit`/`--commit-message`. Each mutating command adds: (a) `require_git_if_commit(root, commit)` before mutating (fail-fast), and (b) **after the `with library_lock` block** (so the lock is released — hook-safe): `if commit: git_commit_all(root, commit_message or auto_message(<verb parts + subject>))`. For `doc add`/`doc format add` the git commit goes between the lock block and source removal. Uniform, mechanical, per-command auto-message.
2. **Two touch points, not one**, because the precheck must run before mutation and the commit after — a single end-of-command helper would mutate-then-fail on a non-git library. If `git_commit_all` fails, the library is already validly mutated (just uncommitted) — a state audit check 5 detects; the command surfaces git's stderr as a ClickException.
3. **`--github` is live-state; only opus runs the real path.** Unit tests mock `_gh`. Opus pilots once against `gh repo create <owner>/shelf-p07-pilot-<n>` and tears it down with `gh repo delete --yes`. Gate-before-mutation: fable + codex concur before the pilot runs.
4. **git identity is ambient.** No fallback committer invented (out of scope); a user without git identity gets git's own error — acceptable.

### Task 1: Git core + commit plumbing helpers

**Files:** Test `tests/test_git_core.py` · Create `src/shelf/core/git.py`, `src/shelf/cli/commit.py`

**Interfaces:**
- `core/git.py`: `is_git_repo(root: Path) -> bool` (a `.git` dir/file present); `git_init(root: Path) -> None` (`git -C root init`, quiet); `git_commit_all(root: Path, message: str) -> None` (`git -C root add -A` then `git -C root commit -m message`; uses ambient identity; **checked subprocess — captures stderr and raises `click.ClickException` on any git failure**, so a failed commit surfaces cleanly rather than crashing); `github_create_and_link(root, owner, name="shelf-library") -> str` (calls `_gh(["repo","create", f"{owner}/{name}", "--private"])`, then explicitly `git -C root remote add origin <url>` — `gh repo create` without `--source` does not link the local repo — returns the URL); `_gh(args: list[str]) -> str` (subprocess to `gh`, returns stdout; the injectable seam).
- `cli/commit.py`: `commit_options(fn)` decorator adding `--commit`/`--no-commit` (default off, param `commit`) and `--commit-message` (param `commit_message`); `require_git_if_commit(root, commit) -> None` (raises ClickException naming `shelf init --git` when `commit and not is_git_repo(root)`); `auto_message(*parts: object) -> str` (`"shelf: " + " ".join(map(str, parts))` — the `map(str, ...)` handles `Path` subjects like orphan-delete and variable arity for migrate/regen).
