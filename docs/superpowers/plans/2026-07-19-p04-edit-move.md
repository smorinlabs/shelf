# P04 Edit and Move Implementation Plan (v0.4.0)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Metadata changes (`doc update` — pure catalog rewrites with the §11.4 field matrix) and physical relocations (`doc move` — the three §11.5 operations with folder moves and `files[]` path rewrites), both crash-safe under the P03 byte-snapshot commit witness.

**Architecture:** Two new command modules (`doc_update.py`, `doc_move.py`) on the canonical locked-mutation pattern. `update` never touches files; `move` stages a folder copy, commits, then removes the old folder (post-commit failure → orphan, audit-detectable, per §5).

**Tech Stack:** As P03; no new dependencies.

**Agent assignments:** red sonnet · green codex (stage or stop; controller commits; collect backgrounded runs via companion `status --wait` and cancel the job after collection) · Task 3 gate fable + haiku.

## Global Constraints

- Spec of record: SHELF-PRD.md §11.4 (`doc update`), §11.5 (`doc move`), §5 (atomicity/conformance), §7 (slug immutability).
- `doc update` freely edits: `--title` (display only — never re-slugs, never moves the folder), `--description`, `--kind` (validated against the kind list), `--add-tag`/`--remove-tag` (repeatable), `--set-tags a,b,c`, `--primary` (must be a format the document has), `--doc-date`/`--clear-doc-date`, `--source`, and for repo-anchored docs `--repo-url`/`--subject`/`--clear-subject`.
- `--added <date>` is `--force`-gated (warns that it desyncs the slug; the P05 audit check flags the desync afterward — by design).
- Anchoring is NOT editable via update: explicit `--topic`/`--repo` options exist only to raise a UsageError pointing at `shelf doc move`. The id/slug is immutable.
- `doc move` takes exactly one of `--topic <name> [--create-topic]` | `--repo <name> [--repo-url <url>] [--subject <label>]`; covers topic→topic, repo→repo, and both anchor-switch directions; physically moves the folder; rewrites every `files[]` path; prints the stale-copied-paths warning to stderr; moving to the current anchor is an error.
- Exit codes: usage 2 · unknown id 3 · conflicts 5 · generic 1. Locked mutations only; move uses the byte-snapshot witness exactly as P03's `doc add` does.
- Implementers never edit `tests/`; Conventional Commits + trailer:
  `Claude-Session: https://claude.ai/code/session_015GDbGv8iA9Zd4iBfY1b2Zx`
- Worktree branch `p04-edit-move`; never the live checkout.

## Plan-level decisions (recorded for the gate)

1. **`-i` guided TTY edit deferred** (§11.4 mentions it): interactive field-editing conflicts with nothing and blocks nothing; it lands with the P08-era interactive polish. PROJECTS.md P04 tasks don't require it.

```python
"""shelf doc update — pure catalog metadata rewrites (PRD §11.4)."""

import click

from shelf.cli.doc_variants import find_doc
from shelf.cli.runtime import get_library
from shelf.core.atomic import library_lock
from shelf.core.catalog import commit_library, load_catalog


def _reject_anchor(ctx, param, value):
    if value is not None:
        raise click.UsageError(
            "anchoring changes relocate the document — use 'shelf doc move'"
        )


@click.command("update")
@click.argument("doc_id")
@click.option("--title", default=None)
@click.option("--description", default=None)
@click.option("--kind", "kind_", default=None)
@click.option("--add-tag", "add_tags", multiple=True)
@click.option("--remove-tag", "remove_tags", multiple=True)
@click.option("--set-tags", default=None, help="Comma-separated replacement tag list.")
@click.option("--primary", "primary_", default=None)
@click.option("--doc-date", default=None)
@click.option("--clear-doc-date", is_flag=True)
@click.option("--source", "source_", default=None)
@click.option("--repo-url", default=None)
@click.option("--subject", default=None)
@click.option("--clear-subject", is_flag=True)
@click.option("--added", default=None, help="Dangerous: desyncs the slug (requires --force).")
@click.option("--force", "-f", is_flag=True)
@click.option("--topic", "topic_", callback=_reject_anchor, expose_value=False, default=None)
@click.option("--repo", "repo_", callback=_reject_anchor, expose_value=False, default=None)
@click.option("--dry-run", is_flag=True)
@click.pass_context
def doc_update(ctx, doc_id, title, description, kind_, add_tags, remove_tags, set_tags,
               primary_, doc_date, clear_doc_date, source_, repo_url, subject,
               clear_subject, added, force, dry_run):
    """Change a document's metadata."""
    fields_given = any([
        title is not None, description is not None, kind_ is not None,
        add_tags, remove_tags, set_tags is not None, primary_ is not None,
        doc_date is not None, clear_doc_date, source_ is not None,
        repo_url is not None, subject is not None, clear_subject, added is not None,
    ])
    if not fields_given:
        raise click.UsageError("at least one field option is required")

    root = get_library(ctx)
    with library_lock(root):
        catalog = load_catalog(root, for_write=True)
        doc = find_doc(catalog, doc_id)
        before = doc.to_dict()

        if kind_ is not None and kind_ not in catalog.kinds:
            raise click.ClickException(f"kind '{kind_}' is not in the kind list")
        if primary_ is not None and primary_ not in {f.format for f in doc.files}:
            raise click.UsageError(f"--primary '{primary_}' is not a format this document has")
        if (repo_url is not None or subject is not None or clear_subject) and doc.repo is None:
            raise click.ClickException("repo fields only apply to repo-anchored documents")
        if added is not None and not force:
            raise click.ClickException(
                "--added desyncs the slug's date prefix — pass --force to proceed"
            )

        if title is not None:
            doc.title = title
        if description is not None:
            doc.description = description
        if kind_ is not None:
            doc.kind = kind_
        if set_tags is not None:
            doc.tags = [t for t in (s.strip() for s in set_tags.split(",")) if t]
        for tag in add_tags:
            if tag not in doc.tags:
                doc.tags.append(tag)
        for tag in remove_tags:
            if tag in doc.tags:
                doc.tags.remove(tag)
        if primary_ is not None:
            doc.primary = primary_
        if doc_date is not None:
            doc.doc_date = doc_date
        if clear_doc_date:
            doc.doc_date = None
        if source_ is not None:
            doc.source = source_
        if repo_url is not None:
            doc.repo.url = repo_url
        if subject is not None:
            doc.repo.subject = subject
        if clear_subject:
            doc.repo.subject = None
        if added is not None:
            doc.added = added
            click.echo("warning: --added desyncs the slug's date prefix (audit will flag it)", err=True)

        after = doc.to_dict()
        changes = [
            f"{key}: {before.get(key)} -> {after.get(key)}"
            for key in sorted(set(before) | set(after))
            if before.get(key) != after.get(key)
        ]
        if dry_run:
            for line in changes:
                click.echo(line)
            return
        commit_library(root, catalog)
    for line in changes:
        click.echo(line)
```

"""shelf doc move — relocate a document (PRD §11.5)."""

import shutil

import click

from shelf.cli.doc_variants import find_doc
from shelf.cli.runtime import get_library
from shelf.core.atomic import library_lock
from shelf.core.catalog import CATALOG_FILENAME, RepoRef, commit_library, load_catalog
from shelf.core.ingest import doc_rel_dir


@click.command("move")
@click.argument("doc_id")
@click.option("--topic", "topic_", default=None)
@click.option("--create-topic", is_flag=True)
@click.option("--repo", "repo_", default=None)
@click.option("--repo-url", default=None)
@click.option("--subject", default=None)
@click.option("--dry-run", is_flag=True)
@click.pass_context
def doc_move(ctx, doc_id, topic_, create_topic, repo_, repo_url, subject, dry_run):
    """Relocate a document (topic, repo, or anchoring change)."""
    if (topic_ is None) == (repo_ is None):
        raise click.UsageError("exactly one of --topic or --repo is required")

    root = get_library(ctx)
    with library_lock(root):
        catalog = load_catalog(root, for_write=True)
        doc = find_doc(catalog, doc_id)
        old_rel = doc_rel_dir(doc)

        if topic_ is not None:
            if doc.repo is None and doc.category == topic_:
                raise click.ClickException(f"'{doc_id}' is already in topic '{topic_}'")
            if topic_ not in catalog.topics:
                if not create_topic:
                    raise click.ClickException(
                        f"unknown topic '{topic_}' — pass --create-topic to create it"
                    )
                catalog.topics.append(topic_)
            doc.repo = None
            doc.category = topic_
        else:
            if doc.repo is not None and doc.repo.name == repo_:
                raise click.ClickException(f"'{doc_id}' is already anchored to repo '{repo_}'")
            doc.category = None
            doc.repo = RepoRef(name=repo_, url=repo_url, subject=subject)

        new_rel = doc_rel_dir(doc)
        if dry_run:
            click.echo(f"would move {old_rel} -> {new_rel}")
            return
        for variant in doc.files:
            variant.path = variant.path.replace(old_rel, new_rel, 1)

        src_dir = root / old_rel
        dest_dir = root / new_rel
        dest_dir.parent.mkdir(parents=True, exist_ok=True)
        shutil.copytree(src_dir, dest_dir)
        before_text = (root / CATALOG_FILENAME).read_text(encoding="utf-8")
        try:
            commit_library(root, catalog)
        except BaseException:
            try:
                committed = (root / CATALOG_FILENAME).read_text(encoding="utf-8") != before_text
            except OSError:
                committed = False
            if not committed:
                shutil.rmtree(dest_dir, ignore_errors=True)
            raise
        shutil.rmtree(src_dir, ignore_errors=True)
    click.echo(f"moved '{doc_id}' {old_rel} -> {new_rel}")
    click.echo(
        "warning: absolute paths previously copied for this document no longer resolve",
        err=True,
    )
