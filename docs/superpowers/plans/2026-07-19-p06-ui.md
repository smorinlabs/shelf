# P06 The UI Implementation Plan (v0.6.0)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to execute this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** The real generated `index.html` — the approved UI direction (dense reading-room list, ⌘K palette, collapsible sidebar, keyboard-driven navigation, inline markdown preview) — plus the local server, enhanced mode, and `shelf open`.

**Architecture:** The approved mockup (`docs/superpowers/designs/2026-07-19-shelf-ui-approved.html`) is the **source of truth** for the page's HTML/CSS/JS. The generator ports it into a tokenized template and injects the real catalog data (metadata + bounded preview snippets) at render time. The page detects its own mode (`file://` core vs `http://` enhanced) at runtime and adapts copy/render behavior. A lightweight package server (`src/shelf/server/`) provides enhanced mode; `shelf open` drives both.

**Tech Stack:** As P05 (stdlib `http.server`, no new deps); the page is dependency-free vanilla HTML/CSS/JS.

**Agent assignments:** red sonnet · green codex (stage or stop; controller commits; cancel collected jobs) · **Task 6 gate: fable, with mandatory manual browser verification via claude-in-chrome** (the orchestration plan's P06 safeguard) · haiku status flips.

## Plan-level decisions (recorded for the gate)

1. **Templating mechanism -> token replacement.** The current `string.Template.substitute` cannot survive a large HTML/CSS/JS file (literal `$`/`{` collisions). The template uses explicit tokens the generator replaces with `str.replace`: `__SHELF_DATA__` (the catalog+snippets JSON), `__SHELF_FINGERPRINT__` (the fingerprint comment body), `__SHELF_DOC_COUNT__`. `render_index` no longer uses `string.Template`. **Script-context safety (Codex review):** `__SHELF_DATA__` is injected into an inline `<script>` (`const PAGE = __SHELF_DATA__;`), so the serialized JSON must be escaped so document content can never break out of the script element. After `json.dumps`, replace these with their backslash-uXXXX forms: `<` -> `\u003c`, `>` -> `\u003e`, `&` -> `\u0026`, and the JS line terminators U+2028 / U+2029 -> `\u2028` / `\u2029`. Replace `__SHELF_DATA__` **last** (single pass) so token-like catalog text cannot be re-rewritten by earlier substitutions.
2. **Preview snippets embedded at generation (bounded).** The generator extracts a bounded snippet (first heading + first paragraph, hard cap ~600 chars) from each document's primary text variant and pre-renders it to escaped, minimally-formatted safe HTML (headings, paragraphs, list items, inline code, one code block). This is metadata-grade, not "bulk content" — so the preview works in **core mode with no fetch**. **PRD §13 gets a one-line clarification** (Task 6): metadata plus a bounded per-document preview snippet is embedded; full contents are never bulk-embedded.
3. **Snippet staleness is out of the fingerprint model.** Snippets derive from document *content*, which the catalog doesn't hash; they refresh on any mutation or `regen`. A content-only change without a catalog mutation won't auto-refresh the snippet — consistent with the existing model (the catalog never tracked content hashes).
4. **`open` becomes real → the last stub is gone.** Task 4 deletes `tests/test_conformance.py::test_stub_leaf_errors_cleanly` (P05 re-pointed it at `open`; after P06 there are no stub leaves left). The `--help` conformance matrix keeps every command.
5. **Server is stdlib.** `http.server.ThreadingHTTPServer` with a hardened handler rooted at the library; no framework dependency.

### Task 1: Preview snippet extraction

**Files:** Test `tests/test_preview.py` · Create `src/shelf/core/preview.py`

**Interfaces:**
- `extract_snippet(text: str, fmt: str, *, max_chars: int = 600) -> str` — returns escaped, minimally-formatted safe HTML (a bounded teaser). Markdown (`md`): render `#`/`##`/`###` headings, paragraphs, `-`/`*` list items, inline `` `code` ``, and a single fenced ```` ``` ```` block; stop at the char cap on a block boundary. HTML (`html`): strip tags to text, take the leading text, wrap in a paragraph. Everything HTML-escaped first so document content can never break the page. Pure, no I/O.
- `build_snippets(root: Path, docs: list[dict]) -> dict[str, str]` — for each raw catalog doc dict, read its **primary** variant file under `root` (the `files[]` entry matching `primary`, else the first text variant), call `extract_snippet` on its text, and map `doc["id"] -> snippet`. A missing/unreadable file → that id maps to `""`. Takes raw dicts (not the `Catalog` model) to avoid the import cycle.

### Task 2: The template + generator data injection

**Files:** Test `tests/test_index_render.py` · Modify `src/shelf/core/index.py`, `src/shelf/templates/index.html.tmpl` · Consumes Task 1.

**Interfaces:** `template_text()`, `parse_fingerprint()` unchanged. `render_index(catalog_text, snippets=None)` rewritten: parse catalog → build a `page_data` dict (`root: ""` placeholder for the server to fill; per-variant library-relative paths; `docs[]` with id/title/kind/anchor/tags/formats/primary and a `snippet` HTML string taken from `snippets[id]` when provided else `""`; `topics`; `kinds`) → serialize to script-safe JSON (decision 1) → read template → replace `__SHELF_FINGERPRINT__`, `__SHELF_DOC_COUNT__`, then `__SHELF_DATA__` **last** → return. `commit_library(root, catalog)` and `regen_cmd` build `snippets = build_snippets(root, [d.to_dict() for d in catalog.documents])` (they hold `root`) and pass it. The template is the approved mockup with its hardcoded `const DOCS = [...]` replaced by `const PAGE = __SHELF_DATA__;` and the app reading from `PAGE.docs`; mode detection (`location.protocol === "file:"`) toggles copy-contents/inline-render; copy-path computes the absolute root from `location` (core) or `PAGE.root` (enhanced, empty in the committed file and filled by the server per-response — Task 3).

**The template porting is a faithful transform of the approved design file, NOT a redesign.** Codex reads `docs/superpowers/designs/2026-07-19-shelf-ui-approved.html` and applies exactly these changes: (a) replace the `DOCS` literal with the `__SHELF_DATA__` token bound to `PAGE.docs`; (b) render each row/preview/palette entry from `PAGE` instead of the static array; (c) replace the hardcoded snippet HTML with `doc.snippet`; (d) add the `file://`-vs-`http://` mode switch driving copy-contents visibility and inline HTML rendering; (e) embed the fingerprint comment via `__SHELF_FINGERPRINT__`. Nothing else about the HTML/CSS/JS changes.

### Task 3: The local server (enhanced mode)

**Files:** Test `tests/test_server.py` · Create `src/shelf/server/__init__.py`, `src/shelf/server/serve.py`

**Interfaces:** `find_free_port(preferred: int) -> int` (returns preferred if bindable on 127.0.0.1, else the next free port); `make_server(root: Path, port: int) -> ThreadingHTTPServer` with a handler that: serves `/` → reads the **current on-disk** `index.html` per request and injects a script-safe JSON-escaped absolute root into `PAGE.root` **in the response body only** (never writing or caching the transformed HTML on disk — so `shelf audit` still validates the committed file and a later `regen` is visible); serves `/docs/...` files under root; **refuses any path resolving outside root** (traversal, symlink escape, absolute paths → 403); binds `127.0.0.1` only. `serve(root, port) -> tuple[server, actual_port]` starts it on a daemon thread.

Root injection detail: the committed `index.html` has `"root":""` in its `PAGE` object; the handler replaces that exact empty value with the JSON-escaped absolute root string in the served bytes. Recompute `Content-Length` from the transformed body.
